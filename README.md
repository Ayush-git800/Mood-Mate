## 💡 Why MoodMate Matters

Most conventional mental health apps are clinical, sterile, and punitive. They guilt-trip users for breaking a streak, charge high subscription fees, and treat sadness or burnout like system bugs to be eliminated.

**MoodMate completely flips this narrative:**

| Conventional Mental Health Apps ❌ | MoodMate 🌿 (Our Solution) ✅ |
| :--- | :--- |
| **Punitive Streaks**: Guilt-trips users when a streak is missed | **Non-Judgmental Weather**: Treats feelings like natural atmospheric weather shifts |
| **Sterile Check-ins**: Boring text fields and dry radio buttons | **Tactile 8-Mood Sanctuary**: 8 responsive emojis with unique atmospheric particle explosions |
| **Fake / Canned AI**: Static repetitive robotic replies | **Live Google Gemini 3.8 Flash**: True multi-turn intelligence (Coding in C++, grounding, science) |
| **Data Selling & Cloud Leaks**: Personal journals sent to remote servers | **100% Zero-Knowledge Privacy**: Isolated local storage (`localStorage`) stays on the user's laptop |
| **Clinical Isolation**: Isolates the user in a sterile dashboard | **Kindness Wall & Virtual Hugs**: Anonymous communal support and celebratory confetti |

## 🚀 Quick Start & Local Setup

### 1. Prerequisites
- **Node.js** (v18.0.0 or higher recommended)
- **npm** or **yarn**

### 2. Clone the Repository
```bash
git clone https://github.com/Ayush-git800/Mood-Mate.git
cd Mood-Mate
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Configure Your Gemini API Key
Create a `.env` file in the root folder:
```env
GEMINI_API_KEY=your_actual_gemini_api_key_here
```
*(Get a free API key in seconds at [Google AI Studio](https://aistudio.google.com/app/apikey)).*

> **Alternative**: You can also paste your API key directly into the app by clicking the 🔑 **Setup API Key** button in the Lumi Chat header!

### 5. Launch the Development Server
```bash
npm run dev
```
Open **`http://localhost:5173`** in your browser.

### 6. Production Build
```bash
npm run build
```
*(Compiles cleanly into `dist/` in ~1.0 second with 0 errors).*

## 🌐 Cloud Deployment Guide

### Option A: Netlify (Fastest Drag & Drop — 30 Seconds)
1. Run `npm run build` to generate the production bundle.
2. Visit **[app.netlify.com](https://app.netlify.com)**.
3. Drag and drop the **`dist`** folder into the manual deploy zone.
4. Your website is instantly live! *(Our included `_redirects` file prevents 404s on page refresh).*

### Option B: Vercel (Recommended via GitHub)
1. Push your repository to GitHub.
2. Go to **[vercel.com](https://vercel.com)** ➔ Import `Mood-Mate`.
3. Under **Environment Variables**, add:
   - `GEMINI_API_KEY` = your Gemini key.
4. Click **Deploy**. Both the client app and serverless `/api/chat` function deploy automatically!

## 🔒 Zero-Knowledge Privacy Architecture

* **No Remote Database**: MoodMate has zero tracking scripts, cookies, or external SQL databases storing your private notes.
* **Client-Side Partitioning**: All personal journals, daily moods, and streaks live solely in the user's browser via `localStorage`.
* **API Key Shielding**: `GEMINI_API_KEY` is loaded through backend serverless proxy routes, preventing key leakage in client bundles.
* **XSS Sanitization**: Markdown outputs are parsed safely to protect against script injection.
